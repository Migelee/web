# Atrium — restaurant menu website

Static, bilingual (Albanian / English) menu site. No build step.

- Open `atrium/index.html`, or run `python3 -m http.server` in this folder.
- The language is chosen from `?lang=sq|en`, then the saved choice, then the browser language.
- **Editing the menu:** change `js/data.js` (names, prices, descriptions in both languages). The page renders from that file.
